# 闲鱼采集器

[English](README.md) | 简体中文

这是一个 Chrome Manifest V3 扩展，用来整理闲鱼页面上公开展示的商品信息。本仓库是扩展的开源版本，不包含原商业版的授权服务、激活码、管理员工具、客户数据、购买入口或宣传资料。扩展界面目前为简体中文。

用户可从弹窗选择三个入口：

- 商品采集：读取当前商品详情页，导出完整文案、字段和商品图片。
- 店铺采集：读取当前店铺可见的列表卡片，导出快速筛选表。
- 搜索商品采集：读取 1～10 个已加载结果批次，导出同一格式的快速筛选表。

店铺和搜索刻意只停留在列表字段。要采集详情，在快速筛选表的“是否导出详细数据”列标记商品，再从最近任务导入该表。扩展只会打开本地任务中已保存的对应商品 ID，并逐件读取详情和图片。

## 输出

快速筛选生成 `闲鱼快速筛选_<店铺或搜索>_<时间>.xlsx`。深度采集每 100 件生成一个 ZIP 分卷：

```text
闲鱼深度采集_<类型>_<时间>_part001-of003.zip
├─ 商品数据.xlsx
├─ <商品ID>_<短标题>/
│  ├─ <商品ID>_商品文案.md
│  └─ <商品ID>_001.jpg
└─ ...
```

XLSX 固定包含商品数据、失败清单和任务说明三个工作表。图片最多 2 并发下载，统一重新编码为质量 0.92 的 JPEG。

## 安装

1. 打开 `chrome://extensions`，启用开发者模式。
2. 点击“加载已解压的扩展程序”，选择本仓库的 `extension/` 目录。
3. 打开已登录的闲鱼页面，在弹窗选择与页面匹配的采集入口。

3.0 使用全新的 IndexedDB 数据结构，不迁移 2.x 数据。

## 隐私

采集数据只保存在浏览器本地。扩展没有统计上报、账号系统或远程授权检查。权限为 `storage`、`activeTab`、`tabs`、`downloads`，以及闲鱼页面和商品图片 CDN 的主机访问权限。

## 使用边界

扩展只读取页面已经公开展示的信息，不绕过登录、验证码、访问控制或频率限制。遇到 403、429、滑块或安全验证时，任务会暂停并切换到商品页，需由用户手工完成验证。单次连续运行最长 60 分钟，本地最多保留最近 20 个任务、90 天。没有运行中的任务时，扩展不会发送请求。

请遵守目标平台规则和适用的法律法规。“想要数”只是观察线索，不代表销量；本项目与闲鱼官方无隶属关系。

## 开发

```powershell
npm ci
npm test
```

测试需要 Node.js 20 或更高版本。项目没有构建步骤，`extension/` 目录本身就是可加载的扩展。
