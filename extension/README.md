# 闲鱼采集器 3.0

Chrome Manifest V3 扩展，仅支持已登录的闲鱼页面。弹窗提供三个采集入口：

- 商品采集：直接读取当前详情页，采集完整字段、原始文案和全部商品图。
- 店铺采集：只读取当前店铺列表基础字段，先导出快速筛选 Excel。
- 搜索商品采集：读取 1～10 个加载批次的列表基础字段，先导出快速筛选 Excel。

店铺和搜索不会直接完整采集全部商品。用户在快速筛选 Excel 的 `是否导出详细数据` 列标记选中项后，从最近任务导入该文件；扩展只对本地任务中匹配的商品 ID 打开详情和下载图片。本公开版不包含授权、计费或账号系统，只处理浏览器本地保存的任务数据。旧列名 `导出图片` 不再兼容。

## 输出

快速筛选输出：

`闲鱼快速筛选_<店铺或搜索>_<时间>.xlsx`

深度采集和单商品采集每 100 个选中商品生成一个 ZIP 分卷：

```text
闲鱼深度采集_<类型>_<时间>_part001-of003.zip
├─ 商品数据.xlsx
├─ <商品ID>_<短标题>/
│  ├─ <商品ID>_商品文案.md
│  ├─ <商品ID>_001.jpg
│  └─ ...
└─ ...
```

XLSX 固定包含 `商品数据`、`失败清单`、`任务说明`。商品图以最多 2 并发下载，解码后重新编码为质量 0.92 的标准 JPEG；透明区域填白，不放大、不裁剪、不保留 EXIF。

## 安装与使用

1. 在 Chrome 扩展管理页开启开发者模式。
2. 选择“加载已解压的扩展程序”，指向本目录。
3. 点击所需的采集入口。
4. 若页面类型不正确，按提示进入具体商品、店铺或搜索页，再次点击扩展。

V3 是全新安装版本，不读取或迁移 V2 数据。

## 风控与恢复

- 列表滚动间隔随机 2～5 秒；深度商品间隔随机 10～20 秒；每完成 10 件休息 60～120 秒。
- HTTP 403、429、滑块、验证码或安全验证会暂停任务并激活商品页，不会自动绕过。
- 用户手工完成验证后，从最近任务点击“继续任务”。浏览器或任务页重开后不会自动发送请求。
- 单次连续运行最长 60 分钟；达到限制后保存断点，等待用户手动继续。
- 本地任务最多保留最近 20 个且最长 90 天。

## 已知限制

- 本公开版只提供本地采集和导出，不包含登录、授权、支付或云端同步。
- 页面 DOM 由闲鱼维护，选择器可能随改版失效；出现页面识别失败时请提交 issue 并附上页面类型和错误提示。
